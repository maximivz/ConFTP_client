# ConFTP_client

---

## Русский

Консольная версия FTP-клиента.

Язык интерфейса: русский.

### Руководство для FTP-клиента

**Сборка:**
С помощью CMake (папка Build используется для `--build`; исходные файлы находятся в соответствующей директории от корня).

**Как пользоваться:**
Использование интуитивно понятно. Только в разделах работы с файловыми системами (при их просмотре) можно написать `help` и узнать дополнительные команды. Управление консольное.

**О шифровании:**
Клиент на данный момент не использует никакого шифрования!!! Используйте его только в своих частных сетях или на свой страх и риск.

## English

Console version of an FTP client.

Interface language: Russian.

### FTP Client Guide

**Building:**
Use CMake (the Build folder is used for `--build`; the source files are located in the corresponding directory relative to the root).

**How to use:**
Usage is intuitive. Only in the file system views (when browsing them) can you type `help` to see additional commands. Console-based.

**About encryption:**
The client currently uses no encryption whatsoever!!! Use it only on your private networks or at your own risk.

## Čeština

Konzolová verze FTP klienta.

Jazyk rozhraní: ruština.

### Příručka pro FTP klienta

**Sestavení:**
Použijte CMake (složka Build slouží pro `--build`; zdrojové soubory se nacházejí v odpovídajícím adresáři od kořene).

**Jak používat:**
Používání je intuitivní. Pouze v částech se souborovými systémy (při jejich procházení) lze zadat `help` a zobrazit další příkazy. Konzolové ovládání.

**O šifrování:**
Klient v současné době nepoužívá žádné šifrování!!! Používejte jej pouze ve svých soukromých sítích nebo na vlastní nebezpečí.
