# ConFTP_client
Console version for FTP CLIENT

RUSSIAN-language

Руководство для  FTP - клиента


#Часть 0: Сборка
Выберите инсталлер для своей системы, установите зайдите в приложение и нажмите на выход из него (8). А потом перезайдите и тогда можно уже пользоваться.

#Часть 1: РЕГИСТРАЦИЯ
При входе в приложение в первый раз вам необходимо выбрать "Добавление нового профиля" (ввести 2).
Затем открываеться пункт URL. Вам необходимо ввести данный вам URL от админа (или сами знаете). Стандартно он выглядит так: ftp://IP:port/ или пример localhost ftp://127.0.0.1:22/. Затем пункт USERNAME и PASSWORD (от админа). И на месте сертификата '-' вписываете или что либо иное оно не работает.

#Часть 2: ВХОД
Выбираем (1) Выбор профиля и выбираем номер (если у вас один профиль то 0 как первый обьект)

#Часть 3: Файл серверной и клиент системы (совет: откройте на полный экран)
Выбираем (3) - сервер система (увидеть что на компе) и (4) - клиент система (увидеть что на твоем пк). Войдя (написав цифру его в этом списке) в любой из них выбирая диретории (type -d) вы входите в них и осматриваете и написав 't' выбирете для отправки. Выбрав файл тогда выберите его для отправки. Также для справки можете использовать команду 'help'. 

Для обьеснения работы предстваьте TOTAL COMANDER (файловый менеджер) (найдите в инете интерфейс как выглядит). Суть такая же: выбираете файл в сервере, выбираете дир в клиенте, нажимаете (6) DOWNLOAD и файл с сервера скачиваеться в ту директорию (папку). Тот же принцип с отправками диреторий: выбрал ту(A-server) выбрал ту(B-client) выбрал UPLOAD(A->B) или DOWNLOAD(A<-B) и оно выполняеться. Знак окончания "Wait: " (означает что вы должны ввести чтото и нажать enter для продолжения)
